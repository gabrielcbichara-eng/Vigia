# VIGIA

**O que é:** Aplicativo similar ao Waze, mas focado em monitorar problemas de infraestrutura urbana da cidade.

**Fundador:** Fred Bichara

**Propósito:** manifestação civil pacífica e digital, sem fins lucrativos. O VIGIA junta dados (com foto obrigatória e protocolo oficial) para pressionar a prefeitura pela opinião pública. Se a prefeitura não resolver, os dados servem de prova para uma ação civil pública, proposta por uma associação civil criada para isso ou pelo Ministério Público ou pela Defensoria.

Detalhes completos na seção "Propósito e estratégia" do `CLAUDE.md`.
